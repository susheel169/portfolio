# Susheel Kumar Gottipalli — Portfolio

A responsive, recruiter-oriented portfolio built with plain HTML, CSS and JavaScript.

## Before publishing

1. Open `index.html`.
2. Replace:
   - `YOUR_EMAIL@example.com` with your real email.
   - `https://github.com/` with your GitHub profile URL.
   - `https://www.linkedin.com/` with your LinkedIn profile URL.
3. Review the project status labels and only change them to "Completed" after the projects are genuinely completed.
4. Add real certificate verification links/details if you have them.
5. If you know your college name, add it to the Education section.

## Publish free with GitHub Pages

1. Create a GitHub repository, e.g. `susheel-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. GitHub will provide your public portfolio URL.

## Alternative

The same three files can be uploaded to Netlify, Vercel, or another static hosting provider.

## Structure

- `index.html` — portfolio content and structure
- `style.css` — responsive design
- `script.js` — navigation, scroll progress and reveal animations
